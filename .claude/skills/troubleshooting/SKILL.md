# 트러블슈팅 기록

- 대상: 이번 세션에서 실제로 겪은 오류. 내가 지정하면 그것만, 아니면 세션에서 찾아서 후보 목록을 먼저 보여줌
- **과제 제출용 정중한 말투** (~했어요)
- 👉 사용, **오류 메시지는 요약하지 말고 원문 그대로**
- 실제로 에러가 난 것과 **에러 나기 전에 막은 것(사전 방지)**은 제목에 구분 표시
- 코드가 관련 있으면 수정 전/후 코드 블록 포함
- 참고 레퍼런스는 공식 문서 링크 (MDN, React, Zustand, TanStack, Vite 등)
- 노션에 붙여넣기 좋은 마크다운으로, 채팅에 출력 (파일 저장은 요청할 때만)

## 형식

```md
- ⚡ 이슈 No.1 (제목)

    **`이슈`**
    👉 [발생한 상태와 오류 메시지 원문]

    **`원인`**
    👉 [오류가 발생한 이유]

    **`해결`**
    👉 [시도한 방법과 최종 해결 방법]

    **`배운 점`**
    👉 [다음에 같은 문제를 만났을 때 확인할 내용]

    **`참고 레퍼런스`**
    - [문서 이름](링크)
```

여러 개면 마지막에 종합 정리 표 (문제 | 원인 | 해결).
