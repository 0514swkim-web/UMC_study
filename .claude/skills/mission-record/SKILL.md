# 미션 마무리

인자: $ARGUMENTS (예: `week4`)

## 1. 최종 점검
1. 워크북 미션 요구사항을 체크리스트로 만들어 현재 코드와 비교 → 빠진 항목 보고
2. 타입 체크 `pnpm exec tsc -p tsconfig.app.json --noEmit` 실행, 결과 보여주기
3. `pnpm build` 실행, 결과 보여주기
4. 브라우저 확인 목록을 나에게 줌 (모든 화면 돌며 Console 빨간 에러 0개, 미션별 동작 확인). 내가 확인했다고 하면 다음 단계

## 2. 미션 태그
```
git tag -a weekN-mission -m "N주차 필수 미션: 설명"
git push --follow-tags
```

## 3. 노션 제출용 미션 기록
- **과제 제출용 정중한 말투**, 노션 마크다운 붙여넣기용으로 채팅에 출력
- 워크북 지시대로 **핵심 코드 + 최종 확인 결과만** (명령어·중간 과정 X)
- 형식:

```md
## ✅ 필수 미션 N. 미션 이름

### 구성
(폴더/라우트 트리)

### 핵심 코드
**설명** (`파일 경로`)
```tsx
(짧은 코드)
```
한두 줄 설명

### 확인 결과
- [x] 확인 항목

### 결과 화면
(스크린샷 자리)
```

- 선택 미션은 `## ☑️ 선택 미션` 으로 따로
- 이어서 `/troubleshooting` 할지 물어보기
